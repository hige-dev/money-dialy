# 支出検索・重複確認と分類ルール作成

## 月をまたぐ検索

カレンダー画面の「支出検索・重複確認」から開きます。開始日・終了日を指定し、利用先・メモの部分一致、カテゴリ、支払元、金額範囲で検索できます。指定期間は最大12か月です。たとえば12月から翌年2月まで検索できます。

検索結果は日付の新しい順に50件ずつ表示します。金額合計は検索結果の金額を合計し、収入なども含めます。文字列検索では英字の大文字・小文字と全角・半角の表記差を正規化します。

月別APIで取得した閲覧可能な明細を使用します。他人の非公開支出は取得せず、金額のみ公開の支出は利用先・メモ・カテゴリの詳細を表示せず編集できません。1か月でも取得に失敗した場合は検索結果を表示しません。

検索結果の明細を選ぶと編集・削除できます。分類修正からのルール作成も利用できます。

## 重複候補の確認

検索後に「重複候補」を開くと、指定期間全体から候補を探します。利用先・カテゴリなどの検索条件で片方の明細が隠れていても比較できます。

次のすべてが一致する、自動取込の明細と取込状態を持たない支出を並べます。

- 利用日
- 金額
- 支払元（未設定の明細は対象外）

自動取込は `importStatus` が `pending` または `complete` の明細です。比較する両方の明細の詳細を閲覧できることが必要です。取込状態のない支出には手入力・一括登録・定期支出が含まれます。

同日同額の別の買い物も候補として表示されます。自動的な統合・削除は行いません。両方のカテゴリ・利用先・メモを確認し、同じ支出なら手入力側を選んで編集・削除できます。削除時は確認ダイアログを表示します。自動取込側を残すと、後から届く詳細通知の補完先を維持できます。

速報と詳細の自動照合は、カード種別・元の利用日・利用者・元の金額を使う既存処理です。この候補表示は、その照合条件を変更しません。

## カテゴリ修正から分類ルールを作る

管理者が自動取込支出を編集し、共有カテゴリへ変更すると「保存後、この利用先の分類ルールを作る」を選択できます。カレンダー・集計・検索の編集画面で利用できます。

チェックして保存すると、支出の保存成功後にメール分類ルール画面が開きます。キーワードに編集前の利用先、カテゴリに修正先を入力済みにします。利用先がない場合はキーワードを入力してください。条件を確認し、保存すると今後の自動取込に適用します。ルール画面を閉じても支出の変更は保存済みです。

キーワードは、取込メールから抽出した利用先・メモの部分一致で判定します。支出に表示される利用先が既存ルールなどで置換されている場合は、メールから抽出される表記に合わせてキーワードを修正してください。同じ条件の既存ルールがある場合、新規保存はせず一覧から確認できます。

ルールはメール取込全体に適用する共有設定です。この導線では個人カテゴリを提案しません。既存支出への一括適用や個人別ルールの作成は行いません。
