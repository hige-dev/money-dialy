# 実装計画

## 目的

GAS画面モックをLambda版の機能構成に近づけ、家計の傾向と設定項目をスマートフォンで確認しやすくする。今回は従来の合意どおり、実データの保存やGmail連携ではなく、サンプル値を使う画面モックを拡張する。

## 調査結果

- Lambda版の定期支出画面には、金額、カテゴリ、メモ、支払日、頻度、支払元、場所などの項目がある。頻度は毎月・隔月・毎年に対応している。
- Lambda版のメールマッピング画面には、件名または本文キーワードを条件に、支払元・カテゴリ・場所を割り当てる設定がある。
- Lambda版の設定画面はカテゴリ・場所・支払元の管理タブと、定期支出・メールマッピングなどへのリンクで構成されている。
- Lambda版の集計画面には、カテゴリ別の月推移を示す積み上げ棒グラフがある。
- Lambda版のカレンダーは日別合計の95パーセンタイルで色の基準を決める。ただし、現在は支出がある日だけを基準にするため、支出日が少ない月は最大額が基準になりやすい。
- GAS画面モックは現在、集計・入力・カレンダーの3画面で、予算は固定値、設定画面とデータ保存は未実装。

## 決定事項

- GAS画面モックに設定画面を追加し、下部ナビゲーションを集計・入力・カレンダー・設定の4項目にする。
- 設定画面は設定項目を羅列せず、用途別の入口を持つハブにする。固定費、メール自動マッピング、支払元・場所・カテゴリ、予算の各項目から一覧と編集フォームへ進む。
- 固定費は金額・カテゴリ・備考・支払日・頻度を設定できるようにする。頻度は初回モックでは毎月・隔月とし、支払元・場所は任意項目として用意する。
- 予算は任意設定にする。未設定時は予算・残額・予算進捗を集計画面から隠す。
- 集計画面にカテゴリ別月推移の積み上げ棒グラフを追加し、Lambda版と同じく直近12か月の推移を表示する。
- 月末予測は固定費を除いた変動費を対象にし、8日目以降に表示する。予測額は経過日数あたりの変動費から推定し、前月の変動費実績と比較する。実績合計と予算進捗には固定費も含める。
- カレンダーの色の基準は95パーセンタイルを使い、支出ゼロの日も含む当月全日の日別合計から算出する。基準を超える金額は最大強度に丸め、大口の単発支出で他の日の色が薄くなりすぎるのを抑える。
- 設定フォームと画面切り替えはブラウザー内のサンプル状態だけで動作させる。スプレッドシート保存、実際の定期登録、Gmail読取・自動分類は今回実装しない。

## 対象範囲

- `gas/webapp-pilot/` の集計、設定、カレンダー画面と下部ナビゲーションを拡張する。
- 固定費、メールマッピング、支払元、場所、カテゴリ、予算の一覧・追加・編集をサンプル操作で確認できるようにする。
- 集計画面にカテゴリ別月推移、任意予算表示、固定費を除いた月末予測を追加する。
- カレンダーに95パーセンタイル基準の金額グラデーションを追加し、大口支出を含むサンプルも用意する。
- ローカルPlaywright確認を4画面に合わせて更新する。
- Lambda、既存のGmail取込処理、React版、本番データには変更を加えない。

## 実装手順

1. 設定ハブ、固定費一覧・フォーム、メール分類ルール一覧・フォーム、マスタ管理、予算設定の画面構成を追加する。
2. 下部ナビゲーションに設定を加え、各設定項目の画面切り替えとサンプル操作を実装する。
3. 集計画面に直近12か月のカテゴリ別積み上げ推移と、設定済み予算・月末予測の表示を追加する。
4. カレンダーに日別支出額のグラデーションを追加し、全日基準の95パーセンタイルで強度を正規化する。
5. 画面幅320、390、480、768、1280pxでレイアウト、4画面切り替え、設定フォーム、下部ナビ、横はみ出しを確認する。
6. 大口の固定費がある場合のカレンダー強度と、固定費を除外した変動費予測を確認する。
7. レビューで見つかった問題を修正し、検証結果を確認してからGASへデプロイする。

## 検証

- Node.js構文確認と`git diff --check`を実行する。
- Playwrightの画面確認で5種類の幅を検証し、集計・入力・カレンダー・設定の画面切り替えを確認する。
- 固定費を含むサンプル値を使い、カレンダーの95パーセンタイル上限と予測対象の分離を確認する。
- GASへデプロイした後、本人限定URLで設定画面、集計、スマートフォン幅を確認する。

## 未対応事項

- Gmailから実際にメールを読む権限・トリガー・自動分類処理。
- 固定費を頻度どおりにスプレッドシートへ自動登録する処理。
- 家計データ、設定値、マスタのスプレッドシート保存。
- 予算と固定費の設定を複数ユーザー間でどう共有するか。

## レビュー反映

- 支払元・場所・カテゴリのマスタを固定費・メール分類フォームに反映し、カテゴリは支出入力にも反映する。
- マスタ名を変更したときは既存の固定費・分類ルール・サンプル内訳の参照値も更新する。既存データが使っている項目は削除できないようにする。
- 予算超過時はマイナスの残額ではなく超過額を表示する。
- 全日基準の95パーセンタイルが0円になる疎な月は、支出日だけを対象に上限を求める。
- 月推移グラフは320px幅でラベルを間引き、月別のカテゴリ金額を展開できる一覧も用意する。
- 集計用の見本データで使っているカテゴリも削除対象から保護し、改名時は入力中の選択・最近の支出・日別明細まで共有データから更新する。
- マスタ切替は未実装のタブ操作ロールを外し、押下状態を伝えるボタン群にする。
- サンプルのない月は最近の支出一覧に空状態を表示し、入力中に選択したカテゴリも理由を案内して削除できないようにする。
