# 計画

## 目的

同じブラウザーで家族用家計簿を開き直した際、前回取得した家計データをすぐに表示し、権限確認と最新データ取得を待つ体感を軽減する。

## 現状の調査結果

- `gas/webapp-pilot/Client.html` はアプリセッションを `localStorage` に保存している。利用者の確認では再ログインなしで自動的に画面が開くが、`getAppData` の完了まで確認画面が表示される。
- `gas/webapp-pilot/Code.gs` の `getAppData` はセッション・Users権限確認、未完了保存の復旧、全画面向けデータの取得を行う。画面生成時は現在のデプロイ世代をHTMLへ渡していない。
- `gas/webapp-pilot/Index.html` と `Styles.html` に常設の更新状況表示はない。設定フォームは動的に再生成されるため、初回の無効化だけでは編集を防げない。
- `gas/webapp-pilot-checks/scripts/visual-check.mjs` は模擬GAS応答でブラウザーのセッション復元・失効・ログアウトとスマートフォン幅を検証する。バックエンド確認にはUsers変更後の権限照合と保存復旧の検証がある。
- `docs/plans/plan_20260927_persistent_browser_login.md` により、セッションは期限なし、各操作で権限を確認し、デプロイ時は世代を更新する。
- `AGENTS.md` に従い、人が読む文章は日本語で記述し、変更後に関連検証を実行する。

## 決定事項

- 利用者は「B: 前回のデータを先に表示」を選択した。
- 正常に取得した家計データと取得時刻をブラウザーに保存する。起動時は同じセッション・デプロイ世代の保存値だけを復元する。別アカウントの新規ログインや新しいデプロイで以前の家計データを先に表示しない。
- 前回データの表示中は取得時刻と「最新データを確認中」の常設表示を行う。集計・月切り替え・フィルター・カレンダーは閲覧可能とし、入力・設定・削除などの変更操作は無効にする。
- 最新データと権限の確認が成功したら画面・ユーザー権限・保存値を更新し、編集を有効にする。通常の保存後の再取得でも保存値を更新する。
- 利用停止・セッション失効の場合は画面内データと保存値を削除し、ログイン画面へ戻す。ログアウトは通信結果にかかわらずブラウザー内のセッション・家計データを削除する。
- 一時的な通信失敗の場合は前回データを閲覧専用で残し、「最新データを確認できていません」と再試行手段を表示する。確認できるまで変更操作を許可しない。
- 保存値が壊れている場合、容量不足、ブラウザー保存が利用できない場合は、従来の最新データ取得後の表示へ戻す。初回利用や初期化待ちには前回データを使わない。
- 起動・再試行の応答がログアウト後に届いても、画面や保存値を復元しない。別タブのログアウト・セッション変更でも現在の古い表示を解除する。

## 解決済みの確認事項

- 起動時の表示方式: 最新応答を待たず、前回取得した家計データを先に表示する。
- ブラウザー保存範囲: セッションに加えて家計データを保存する。
- 前回データの扱い: 前回値と明示し、権限・最新データ確認までは閲覧専用とする。

## 対象範囲

- `gas/webapp-pilot/Client.html`: 保存・復元、起動状態、編集ガード、再試行、更新・削除・応答競合の扱い。
- `gas/webapp-pilot/Code.gs` と `Index.html`: 非秘密のデプロイ世代を画面へ渡すことと、更新状況の表示領域。
- `gas/webapp-pilot/Styles.html`: スマートフォンでも読みやすい更新表示と無効操作の表示。
- `gas/webapp-pilot-checks/scripts/visual-check.mjs` と必要なバックエンド確認: 起動中・失敗・再試行・失効・ログアウト・保存不可・世代違いの検証。
- 関連README: 家計データのブラウザー保存と削除、前回値の表示について更新。

## 作業手順

1. 承認後、開発エージェントでセッションと世代に紐づく保存形式と起動状態を実装する。
2. 表示時刻と更新状態を表示し、動的フォームを含む全変更経路に確認待ちガードを設ける。
3. 更新成功・失敗・失効・ログアウト・別タブ変更時の状態遷移と応答競合を処理する。
4. 遅延させた模擬応答で、応答前の前回表示と編集停止、応答後の最新表示を検証する。既存画面と保存動作も検証する。
5. 独立したレビューを行い、P0・P1・P2の指摘がなくなるまで修正する。
6. 既存の専用デプロイスクリプトで同じURLへ公開する。既存方針に従い世代を更新するため、公開後の初回は再ログインとデータ取得が必要になる。二回目以降に前回値の表示を利用できる。

- 実行コマンドと結果を報告し、模擬応答による確認と実GAS上の所要時間・ブラウザー確認を区別する。

## リスク

- 利用停止・失効をサーバーから確認する前は、このブラウザーに保存された以前の家計データが表示される。新しいデータ取得・変更はサーバーの権限確認を継続する。
- スプレッドシート変更から再取得まで前回値が古い可能性がある。取得時刻と更新状態を明示する。
- 家計データ量によってブラウザー保存容量を超える可能性がある。保存失敗は通常起動へ戻し、アプリ利用を妨げない。
- GASの最初のHTML取得時間は残る。今回の改善はHTML到着後のデータ取得待ちに対するもので、実GAS応答時間の短縮を保証しない。
